# 🐱 Sistema de Gerenciamento de Gatos Resgatados

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema web para auxiliar uma protetora independente de gatos na organização e no gerenciamento das atividades relacionadas ao resgate e cuidado dos animais.

A proposta surgiu a partir da identificação de dificuldades na organização das informações, dos cuidados veterinários e das doações recebidas.

O objetivo é facilitar a rotina da protetora, centralizando informações importantes em um único sistema.

## 🎯 Objetivo

Desenvolver uma solução simples e acessível que contribua para a organização das atividades da protetora, reduzindo tarefas manuais e facilitando o acompanhamento dos animais resgatados.

## ⚙️ Funcionalidades

* **Cadastro de gatos:** registro e consulta das informações dos animais resgatados.
* **Cuidados veterinários:** registro e acompanhamento dos cuidados realizados.
* **Controle de doações:** registro das doações recebidas.
* **Painel inicial:** visualização de informações gerais do sistema.

## 💻 Tecnologias utilizadas

* Python
* Flask
* SQLite
* HTML
* CSS

## 🚀 Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/Marluce-Almeida/sistema-gerenciamento-gatos.git
```

### 2. Entrar na pasta do projeto

```bash
cd sistema-gerenciamento-gatos
```

### 3. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 4. Executar o sistema

```bash
python app.py
```

### 5. Acessar no navegador

Abra o endereço:

http://127.0.0.1:5000

O projeto foi desenvolvido como parte de uma atividade acadêmica, com foco na criação de um MVP (Produto Mínimo Viável), buscando atender a uma necessidade real identificada junto a uma protetora independente de gatos.

A proposta prioriza a simplicidade, a organização das informações e a facilidade de utilização.
